# Задание 6

## Пример задания
Исполнитель Черепаха действует на плоскости с декартовой системой координат. В начальный момент Черепаха находится B начале координат, её голова направлена вдоль положительного направления оси ординат, хвост опущен. При опущенном хвосте Черепаха оставляет на поле след в виде линии. В каждый конкретный момент известно положение исполнителя и направление его движения. У исполнителя существует 6 команд: Поднять хвост, означающая переход к перемещению 6eз рисования; Опустить хвост, означающая переход в режим рисования; Вперёд n (где n  — целое число), вызывающая передвижение Черепахи на n единиц в том направлении, куда указывает её голова; Назад n (где n  — целое число), вызывающая передвижение в противоположном голове направлении; Направо t (где t  — целое число), вызывающая изменение направления движения на t градусов по часовой стрелке, Налево t (где t  — целое число), вызывающая изменение направления движения на t градусов против часовой стрелки. Запись Повтори k [Команда1 Команда2 ... КомандаS] означает, что последовательность из S команд повторится k раз.

 

Черепахе был дан для исполнения следующий алгоритм:


```
Повтори 7 [Вперёд 17 Направо 90 Вперёд 26 Направо 90]
Поднять хвост
Вперёд 4 Направо 90 Вперёд 6 Налево 90
Опустить хвост
Повтори 7 [Вперёд 278 Направо 90 Вперёд 345 Направо 90].
```

Определите, сколько точек с целочисленными координатами будут находиться внутри объединения фигур, ограниченных заданными алгоритмом линиями, включая точки на линиях.

## Ход решения

В этом задании используем встроенный модуль `turtle`.

1. Подготавливаем черепаху согласно условию: `В начальный момент Черепаха находится B начале координат, её голова направлена вдоль положительного направления оси ординат, хвост опущен`. "положительного направления оси ординат" - это замудренный способ сказать "смотрит вверх". Изначально пайтоновская черепаха смотрит вправо, стоит в нуле, хвост опущен. Нам как правило нужно ее 
- прогоняем указанный алгоритм, видим фигуру (как правило, это два пересекающихся прямоугольника)
- добавляем сетку из точек, если нужно
- Как обычно, внимательно читаем что от нас хотят - Делаем подсчет площади/количества точек внутри пересечения или объединения/находим Х при котором итд.

## Модуль turtle и необходимые функции

Импорт и необходимые функции (и их компактные синонимы в комментариях):
```py
from turtle import * # имортируем ВСЕ из модуля turtle

setheading(90) # или seth(90) - заставить черепаху смотреть в данном направлении
# как на тригонометрическом круге - 0 - вправо, 90 - вверх, 180 - влево, 270 - вниз
# На ЕГЭ перед стартом алгоритма  пишут setheading(90) (направление «вверх», вдоль оси OY), если в условии сказано «хвост направлен вдоль оси ординат».

forward(d) # или fd(d) — движение вперед на d пикселей.
backward(d) # или back(d) или bk(d) — движение назад на d пикселей.
right(angle) # или rt(angle) — поворот направо (по часовой стрелке) на angle градусов.
left(angle) # или lt(angle) — поворот налево (против часовой стрелки) на angle градусов.

# Управление хвостом (Рисование / Перемещения)
pendown() # или down() или pd() — опустить хвост. Черепаха начинает оставлять след при движении.
penup() # или up() или pu() — поднять хвост. При движении черепаха ничего не станет рисовать.
goto(x, y) # или setpos(x, y) — мгновенно переместить черепаху в точку с координатами (x, y).
dot(size, 'red') # поставить точку диаметром size пикселей в текущей координате (можем указать цвет). Идеально подходит для отрисовки сетки (dot(3) или dot(4)).

tracer(0) # полностью отключает анимацию. Без этой команды Python будет отрисовывать каждую точку сетки по очереди, и программа «зависнет» на пару минут. С ней — результат появится мгновенно.
update() # принудительно обновляет экран. Вызывается один раз в самом конце, чтобы показать рисунок.

done() # удерживает окно открытым после завершения работы алгоритма. Ставится в самой последней строчке кода.
exitonclick() # то же самое, но позволяет закрыть окно по нажатию на рисунок

# Вспомогательное (Визуальное удобство)

color('red') # меняет цвет линии/точки (например, 'red', 'black'). Помогает отделить контур фигуры от сетки координат.

```


## Шаблон решения

```py
from turtle import *

tracer(0) # выключаем анимацию, чтобы не терять время. Можем закоментировать, если начались непонятки с рисунком - для отладки

seth(90) # это ставим, если в условии есть: "В начальный момент Черепаха .. вдоль положительного направления оси ординат"
# черепаха стартует в нуле, и хвост ее опущен. Как правило, это совпадает с условием
# но составители могут сойти с ума и начать с произвольной координаты.
#  Внимательно читаем условие и если оно поменялось, подгоняем черепаху:
# up()
# goto(po,usloviu)
# down()

color('red') # если хотим

# ============= Решение задачи

# вставляем прямо сюда условие
# Повтори7 [Вперёд17 Направо90 Вперёд26 Направо90]
# Поднять хвост
# Вперёд 4 Направо 90 Вперёд 6 Налево 90
# Опустить хвост
# Повтори7 [Вперёд278 Направо90 Вперёд345 Направо90].

# задаем переменную для масштаба. Потом подберем исходя из получившейся фигуры
# все "Вперёд17" преврятятся в "Вперед(17*k)"
k = 1

for i in range(7): # повтори 7
    fd(17*k) # Вперёд 17
    rt(90) # Направо 90
    fd(26*k) # Вперед 26
    rt(90) # Направо 90

up() # поднять хвост

fd(4*k) # Вперёд 4
rt(90) # Направо 90
fd(6*k) # Вперед 6
lt(90) # Налево 90

down() # Опусти хвост

for i in range(7): # повтори 7
    fd(278*k) # Вперёд278
    rt(90) # Направо 90
    fd(345*k) # Вперед 345
    rt(90) # Направо 90

# фигура к этому моменту готова - подбираем k


# ============= в конце программы всегда вызываются эти две функции
update()
done()
```
